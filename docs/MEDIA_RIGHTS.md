# 素材权利中心

## 目标

素材权利中心为已入库的媒体素材提供可审计的权利状态、许可信息、地域范围、有效期和证据引用。它只记录人工或授权来源提供的权利事实，不根据文件类型、来源平台或抓取结果推断“可商用”。

## 数据边界

- `unknown`：尚未完成权利核验；新入库素材默认处于此状态。
- `pending_review`：已进入人工核验队列。
- `approved`：已有许可类型或证据 URL，且由工作区成员确认。
- `restricted`：存在地域、用途、平台或其他限制，必须结合备注和证据使用。
- `expired`：已超过 `valid_until`，不能继续视为有效许可。

每条记录保留 `source_kind`（`live` 或 `imported`）、证据 URL/备注、核验人和核验时间。素材没有权利记录时，列表仍返回该素材并显示 `unknown`，不会隐藏风险，也不会补充估算结论。

## API

- `GET /api/v1/storage/rights`：按工作区分页读取素材及其权利状态，支持状态、搜索和分页筛选。
- `PATCH /api/v1/storage/artifacts/{artifact_id}/rights`：工作区 owner/admin/editor 更新或创建权利记录。`approved` 至少需要许可类型或证据 URL；有效期不能逆序；地域列表会去重。

更新动作写入 `media_artifact.rights.updated` 审计事件。接口不会删除原始素材、修改下载记录，也不会向第三方平台声明拥有版权。

## UI 使用约束

“素材权利”页面展示待核验素材、状态、许可类型、权利人、地域和有效期，并提供证据字段。页面明确提示：状态是工作区核验记录，不等价于法律意见或平台商业授权。真实商业使用前仍需由权利人或法务确认许可范围。

## 当前限制

本地闭环已包含数据库、工作区隔离、审计、API、前端和自动化测试；尚未接入外部版权数据库、平台素材授权 API 或自动法律判断。外部授权接入必须在获得凭证并确认服务条款后，以 `live` 或 `imported` 来源写入，不得用 mock 结果替代。
