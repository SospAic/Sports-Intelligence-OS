# Prompt 09 管理后台

## 1. 交付范围

Prompt 09 将此前分散的功能页整合为同一个中文管理后台。登录后使用左侧导航、顶部全局搜索、同步状态、通知失败计数、快速创建、主题切换和用户菜单。桌面端优先，侧栏在窄屏变为可关闭抽屉。

核心页面全部读取真实后端 API：

| 页面 | 数据与操作 |
| --- | --- |
| `/dashboard` | 账号、作品、当日新闻/作品、热点事件、规则求值、通知投递和最近任务汇总；账号快照趋势与真实排行 |
| `/accounts`、`/accounts/{id}` | 组合筛选、分页、CSV、添加、手动同步、快照趋势、作品、同步记录与设置 |
| `/contents`、`/contents/{id}` | 播放/增长排序、高级筛选、保存浏览器视图、CSV、批量创建选题、快照与派生指标 |
| `/news`、`/news/{id}` | 卡片/表格/时间线、筛选、来源与时间边界、事件/生成入口 |
| `/events`、`/events/{id}` | 热度与来源排序、收藏、来源时间线、内容生成 |
| `/topics` | 作品/新闻/事件/人工选题的持久化列表、优先级、状态流转与审计 |
| `/generate`、`/generations` | 热门作品/新闻/事件选择、规则预设、一键生成、结构化成品、重写、保存、复制与导出 |
| `/rules` | 面向运营人员的版本化规则管理；Prompt 与工作流保留为内部版本审计能力，不进入主导航 |
| `/automations` | 无需手写 JSON 的嵌套 AND/OR/NOT 条件构建器、动作排序、JSON 高级模式和执行历史 |
| `/notification-channels` | Provider 动态配置、后端验证与加密保存、启停、确认后测试和投递历史 |
| `/tasks`、`/logs` | 平台/新闻同步、生成、Worker 任务汇总；系统事件与审计记录 |
| `/settings` | 用户/工作区、API/数据库/Redis 健康、LLM/通知 Provider 状态和新闻源同步 |

## 2. 新增后端闭环

### 选题库

0008 迁移新增 `saved_topics`。`source_type` 区分 `content`、`article`、`event` 和 `manual`，同时保留 `source_id`、来源快照元数据、创建人、优先级、状态、备注与时间。`POST /topics/batch` 最多处理 100 个来源，并验证来源属于当前工作区；重复来源幂等返回已有选题。自动化 `create_topic` 动作现在写入同一实体，不再用系统日志冒充选题。

### 运营读取 API

- `GET /operations/tasks`：汇总 TaskRun、平台同步、新闻同步和生成运行，支持类别、状态与分页。
- `GET /operations/events`：读取安全系统事件。
- `GET /operations/audits`：读取工作区审计摘要，不返回 IP 哈希、凭证或 Provider 原始秘密。

## 3. 权限和安全

- 所有服务端页面先验证 HttpOnly 会话；浏览器请求继续携带工作区 ID。
- 写操作先轮换 CSRF Token，再由后端执行工作区角色校验。
- Viewer 只读；Analyst 可同步和管理选题；Editor 可管理账号、自动化和内容；通知渠道仅 Owner/Admin 可写。
- 通知配置读取响应只有 `config_masked`。密码、Bot Token、签名密钥和 API Key 不进入 React 状态以外的持久化存储，也不写日志。
- 真实通知测试会要求用户确认；本次自动测试没有真实渠道凭证，只验证明确标记的 Mock Provider。

## 4. 数据状态与真实性

每个数据页提供加载、空、错误、重试或分页状态。账号、作品和选题显示 `live`、`imported` 或 `mock` 来源标签。指标为空时显示 `—`；前端不会用零值或静态示例数字补齐未采集字段。保存视图只保存筛选偏好到浏览器，不保存或伪造业务数据。

## 5. 当前限制

- 全局搜索首期搜索页面与功能入口，不是跨领域全文检索。
- 仪表盘通过多个有界 API 并行聚合；数据量扩大后可增加专用只读聚合端点和缓存。
- 列显示设置首期由固定高价值列和保存筛选视图实现，尚未提供用户级服务端列布局同步。
- 自动化编辑已发布为直接编辑当前规则定义；完整规则版本发布流和动作原子批量更新仍是后续增强项。
- Prompt 10 将补浏览器 E2E、完整 PostgreSQL 集成、安全回归和正式验收脚本。
