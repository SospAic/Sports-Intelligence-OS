# 热点情报中心数据与功能审计（2026-08-15）

## 结论

排行榜单重复项的主因不是前端 `key` 或 React 重复渲染，而是分析接口把
`trend_topics` / `trend_videos` 的**追加式历史快照**直接当作当前候选集。
同一个平台实体每次采集都会新增一行，原 `/trends/aggregate` 在排行榜、平台
指数和分类矩阵中重复累加这些行。

运行库只读统计证据：近 30 天有 23,828 条话题观测，但仅 490 个唯一的
“平台 + 规范化话题”；视频/资讯有 131,894 条观测，但仅 2,313 个唯一的
“平台 + external_id”。其中 web 资讯还有 1,367 条观测、340 个 feed-scoped
键，但只有 320 个 canonical article，20 篇文章被不同 RSS feed 重复投影。
因此重复项和热度膨胀均是可复现的数据投影缺陷。

## 核查范围

- 采集：已监控账号样本、YouTube Data API、公开 RSS/Atom 源。
- 存储：`trend_topics`、`trend_videos`、`trend_keyword_snapshots` 的快照语义、
  来源标记、观测时间和外部实体标识。
- API：dashboard、topics、videos、keywords、aggregate、score explain。
- 前端：热点情报中心四个 Tab、平台/分类/窗口筛选、SSE 更新和排行榜渲染。
- 指标：热度、爆发分、平台指数、分类矩阵、来源范围和置信度元数据。

## 已修复

1. `/trends/aggregate` 只使用 `source_kind=live` 且满足发布时间/观测窗口的
   数据；未验证或导入数据不会进入默认热点排行榜。
2. 排行榜和指数/矩阵按“平台 + 规范化话题标题”或实体稳定键只保留最新观测；
   平台视频使用 `platform + external_id`，web 资讯优先使用
   `metadata.source_article_id` canonical URL，历史快照继续保留用于审计和时间线。
3. 时间线按“日期 + 实体”去重后再汇总，避免同一实体在同一天重复采集造成热度
   虚高；跨天观测仍保留为历史趋势。
4. 合并话题和视频候选后按 0–100 分数排序，不再固定把全部话题排在视频前面。
5. `days` 参数限制为 1–90 天，服务层也做边界收敛，防止异常窗口扩大扫描。
6. 接口返回原始观测数和去重实体数，前端明确显示数据范围及去重结果。
7. 修复 Compose 可选配置 `SIO_MEDIA_STORAGE_QUOTA_BYTES=` 为空时导致 API
   启动失败的问题：空字符串现在按未设置处理。该问题曾阻断最新镜像部署，
   与热点业务逻辑无关但属于本轮部署门禁发现的运行缺陷。
8. 新闻事件列表增加非破坏性 read-model 去重：同一工作区、同一
   `normalized_title` 只展示当前排序下的最佳事件，历史事件、文章关联和合并/拆分
   审计记录不删除。该处理覆盖了历史同步跨越聚类回看窗口后形成的重复事件行。

## 指标合理性边界

- `heat_score` / `breakout_score` 是 0–100 的派生排序分，不是平台原始热度、播放
  或搜索量；它们必须继续显示来源、算法版本、权重、样本量和置信度元数据。
- 已监控账号样本的播放、互动来自平台适配器返回的公开或授权字段；缺失字段不以
  估算值补齐。公开 RSS/Atom 的资讯实体没有播放/互动原始指标，其分数只由新鲜度、
  源位置和来源可靠性组成，并标记 `metric_available=false`。
- 平台指数和分类矩阵现在按当前去重实体的派生分求和后归一化，适合比较当前候选
  集，不应解释为平台官方指数或跨平台绝对规模。
- 话题词来自受控体育词表和显式 hashtag；它是线索聚合，不等于经过人工确认的
  事件实体。跨语言同义词、赛事/人物实体归一化和真正事件聚类仍需独立实体层。

## 尚未完成但不能伪造为完成

- 全网趋势榜单仍受已配置公开源、已监控账号和 YouTube API 权限限制；没有凭证或
  来源时页面必须显示空状态/条件提示。
- RSS 同源转载的不同 canonical URL 仍可能作为不同资讯证据保存；后续应增加基于
  规范化 URL、标题/摘要相似度和事件簇的可审计去重，而不是静默删除来源证据。
- 新闻事件的列表去重是展示投影，不等于历史数据合并；相同标题但确实属于不同时间
  事件时仍需要人工合并/拆分或下一版时间实体模型确认。
- 热度模型还没有固定体育事实评测集、人工采纳率、预测与实际增长回测，以及每日
  平台 canary；当前只能称为可解释的派生排序分。
- 历史快照没有删除；生产环境需要后续完成存储生命周期、索引/分区和备份恢复演练。
